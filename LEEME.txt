REGISTRO DE PRODUCTOS

REQUISITOS

- PHP 8.5.11 
- PostgreSQL 18.6


INSTALACIÓN

1. Clonar el repositorio:
   git clone https://github.com/IvanParada/product-registration-system.git

2. Crear una base de datos PostgreSQL llamada:

   prueba_productos

3. Ejecutar el script:
   
   SQL/database.sql

   Desde línea de comandos:
   
   psql -U postgres -d prueba_productos -f SQL/database.sql

   También puede ejecutarse desde TablePlus o pgAdmin sobre la base
   prueba_productos.

4. Configurar la conexión a la base de datos en:

   php/config/database.php

   Configurar:
   - host
   - port
   - user
   - password
   - dbname

5. Verificar que PHP tenga habilitadas las extensiones:
   
   extension=pdo_pgsql
   extension=pgsql

1. Desde la raíz del proyecto ejecutar:
   
   php -S localhost:8000

1. Abrir en el navegador:
   
   http://localhost:8000
